# cryptarium

**Cryptographic discovery and CBOM generation for the post-quantum transition.**

A Go-based CLI that scans a **local path** or **public HTTPS git URL**, inventoring cryptography across four evidence sources and emitting a CycloneDX CBOM, SARIF, and a prioritized migration report.

<CardGroup cols={4}>
  <Card title="Source" icon="code" href="/concepts/evidence-sources">

  </Card>
  <Card title="Dependencies" icon="cubes" href="/concepts/evidence-sources">
    Go `go.mod` against a known-library catalog (v0.2).
  </Card>
  <Card title="Certificates" icon="certificate" href="/concepts/evidence-sources">
    X.509 / PKCS#12 metadata — algorithm, size, curve, validity.

Unlike single-source scanners, it correlates all four evidence sources so a finding is a linked picture, not four disconnected lists.

## At a glance

| Area | Supported today (v0.3) |
|---|---|
| **Targets** | Local directory, or public HTTPS git URL (shallow clone; requires `git` on `PATH`). SSH / private remotes: roadmap |
| **Source languages** | Go, Python, JavaScript / TypeScript, Java, C / C++ (OpenSSL, libsodium, mbedTLS, Crypto++, Botan, …) |
| **Dependency manifests** | Go only (`go.mod`) |
| **Certificates & keys** | `.pem`, `.crt`, `.cer`, `.der`, `.key`, `.p12`, `.pfx` |
| **Outputs** | Markdown (default), JSON, CycloneDX CBOM 1.6+, SARIF |
| **CI** | GitHub Action; `--fail-on` |
