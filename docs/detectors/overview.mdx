# Detectors overview

Cryptarium looks for cryptography in four places. Source coverage is mostly YAML [rule packs](/detectors/rule-packs), not hardcoded Go.

**What you will do next:** skim this page, then [add a rule](/detectors/adding-a-rule) when you need a new API covered.

## The four places

| Detector | Looks at | You get |
|---|---|---|
| **Source** | Go, Python, JS/TS, Java, C/C++ via rule packs | Call sites, algorithm names, parameters |
| **Dependencies** | `go.mod` + library catalog | Crypto libraries present (not proof of use) |
| **Certificates** | PEM, DER, PKCS#12 files | Algorithms, sizes, curves, validity (metadata only) |
| **Configuration** | nginx TLS, SSH, JWT `alg`, similar | Configured suites and algorithms |

<Tip>
  A library listed in `go.mod` is medium confidence at most until it correlates with a source finding. See [Confidence](/concepts/confidence).
</Tip>

## From file to report

1. **Detect** evidence in those four places.
2. **Correlate** related hits (for example a dependency and a matching call).
3. **Classify** quantum risk (Broken / Weakened / Safe / Unknown).
4. **Score** priority and emit CBOM, SARIF, or a Markdown report.

Rules find evidence. They do not decide quantum risk. That stays in the classifier so claims stay citation-backed.
