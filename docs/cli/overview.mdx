# CLI overview

`cryptarium` is a Go CLI. The primary command is `scan`. It accepts a **local directory** or a **public HTTPS git URL**.

| Command | Purpose |
|---|---|
| `cryptarium scan <path or git-url>` | Discover crypto, classify, score, and emit outputs |
| `cryptarium version` | Print version |
| `cryptarium help` | Show help |

```bash
cryptarium scan .
cryptarium scan https://github.com/OWNER/REPO
cryptarium scan . --format cbom --output cbom.json
cryptarium scan . --fail-on critical
```
