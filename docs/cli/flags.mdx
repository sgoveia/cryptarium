# Flags & exit codes

**Purpose:** Control formats, filters, policy thresholds, and determinism for `cryptarium scan`.

## Usage

```
cryptarium scan [flags] <path|git-url>
```

## Common flags

| Flag | Description |
|---|---|
| `--format` | Output format: `json`, `cbom`, `sarif`, `markdown` (repeatable). `html` may appear in `--help` but is not implemented yet |
| `--output` | Output path, `-` for stdout, or a directory when emitting multiple formats |
| `--rules` | Additional rule-pack directory loaded after the defaults (repeatable) |
| `--exclude` | Glob to exclude (parsed; wiring may still evolve) |
| `--include-tests` | Include test files and fixtures at normal scoring (parsed; wiring may still evolve) |
| `--fail-on` | Fail when priority reaches `critical`, `high`, `medium`, `low`, or `none` (default) |
| `--policy` | Policy file path (stub / evolving) |
| `--concurrency` | Worker count (default: NumCPU) |
| `--deterministic` | Suppress timestamps and machine-specific metadata |
| `-v` / `--verbose` | Verbose logging |

Run `cryptarium scan --help` on your installed version for the authoritative list.

## Exit codes

| Code | Meaning |
|---|---|
| `0` | Success (no threshold breach) |
| `1` | Findings met or exceeded `--fail-on` |
| `2` | Scan error (bad target, clone failure, invalid rules) |
