# Markdown report

**Purpose:** Human-readable migration report — findings grouped by severity with location, classification, target, and priority.

**When to use:** Forward to an architect or migration owner; attach to a change ticket.

## Example

```bash
cryptarium scan . --format markdown --output CRYPTO-REPORT.md
```

Markdown is the default format when `--format` is omitted. HTML output is not implemented yet.

## How to read it

See [Reading the migration report](/guides/migration-report) for priority bands, classification columns, and recommended next actions.
